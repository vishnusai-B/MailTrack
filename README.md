# MailTrack

Production-oriented Gmail email engagement tracking platform (Monorepo Foundation).

## Workspaces

- `apps/extension`: Chrome Extension (Manifest V3, TypeScript)
- `apps/dashboard`: React + Vite + TypeScript + Tailwind CSS web dashboard
- `apps/server`: Node.js + Express + TypeScript + PostgreSQL + Prisma ORM backend
- `packages/shared`: Reusable TypeScript types (`User`, `TrackedEmail`, `TrackingEvent`, `HealthCheckResponse`)
- `docs`: Setup and architecture documentation
